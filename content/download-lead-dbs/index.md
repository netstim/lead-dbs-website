**Prerequisites:**

- Recommended RAM size: 32GB or more
- MATLAB: R2024b or later
- MATLAB Image Processing Toolbox
- MATLAB Signal Processing Toolbox
- MATLAB Statistics and Machine Learning Toolbox
- MATLAB Curve Fitting Toolbox (optional)
- MATLAB Parallel Computing Toolbox (optional)
- SPM12

Click on one of the buttons below to download Lead-DBS including several [subcortical atlases](/helpsupport/knowledge-base/atlasesresources/atlases-2/). Check out our [manual](https://netstim.gitbook.io/leaddbs) on how to setup and use the toolbox.

Experimental standalone versions can run without MATLAB installed. However, it’s recommended to use normal version if possible, since standalone versions won’t receive regular updates or hotfixes.
