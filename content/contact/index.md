## Contact

The quickest ways to get help with Lead-DBS:

- **Questions about using Lead-DBS:** ask on the [user Slack](https://inviter.co/lead-dbs) (the link is the self-invite), where users and developers help each other.
- **Bug reports and feature requests:** open an issue on [GitHub](https://github.com/netstim/leaddbs/issues).
- **Installation and how-to:** see the [Lead-DBS manual](https://netstim.gitbook.io/leaddbs).
